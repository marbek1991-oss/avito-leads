Поиск потенциальных клиентов

Автоматический поиск не подключён. У этого бесплатного приложения нет доступа к базе объявлений Авито. Кнопки ниже открывают обычную поисковую выдачу для ручной проверки. Приложение не изображает результаты найденными и не обходит ограничения площадки.

Режим поиска: обычная выдача поисковика по сайту avito.ru, без автоматического сбора объявлений и проверки актуальности.

Как подключить настоящий автопоиск

Понадобится разрешённый поставщик данных с доступом к объявлениям Авито, сервер для запуска по расписанию и проверка прямых ссылок. После подключения можно автоматически заполнять эту базу и формировать персональные сообщения. Одной HTML-страницы на GitHub Pages недостаточно.

Ежедневное задание ChatGPT, которое мы ранее настроили, работает отдельно от этого приложения. Его результаты можно импортировать CSV-файлом.

Резервная копия и перенос

Финансовые и клиентские сведения не загружаются в GitHub. Данные этой версии находятся в хранилище браузера конкретного устройства и могут исчезнуть при его очистке.

Установка на телефон

Опубликуй эти файлы в отдельном репозитории GitHub Pages, чтобы не заменить приложение «Мои финансы». В Safari: «Поделиться» → «На экран Домой». В Chrome на Android: меню ⋮ → «Добавить на главный экран».
