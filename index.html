Поиск потенциальных клиентов

Прямой поиск на Авито недоступен. Бесплатный вариант — Google Alerts RSS с проиндексированными ссылками (подключение ниже). Актуальность объявлений не подтверждена. Кнопки ниже открывают обычную поисковую выдачу для ручной проверки.

Режим поиска: обычная выдача поисковика по сайту avito.ru, без автоматического сбора объявлений и проверки актуальности.

Результаты ежедневного задания

Если настроен разрешённый источник данных, GitHub Actions сохраняет новые ссылки в candidates.json. Можно забрать их в свою базу одним нажатием. Импорт не подтверждает актуальность объявления.

Источник ещё не проверен

Здесь появится дата проверки, число записей в RSS и причины отсева.

Несколько бесплатных Google Alerts RSS

Ежедневное задание читает несколько RSS-лент из переменной GOOGLE_ALERTS_RSS_URL, удаляет повторы и добавляет до 15 новых ссылок за запуск. Важно: Google Alerts не гарантирует новых клиентов и не проверяет актуальность объявлений.

Рекомендуемые запросы для проверки: site:avito.ru "модульный дом", site:avito.ru "баня под ключ", site:avito.ru "бытовка", site:avito.ru "газоблок", site:avito.ru "откатные ворота", site:avito.ru "световые вывески". Они могут дать более релевантную выдачу, но не гарантируют новых объявлений.

Для улучшения охвата создавай отдельные оповещения с более конкретными формулировками (по желанию меняй существующие, но не удаляй RSS-ссылки без обновления GitHub):

  1. site:avito.ru "модульные дома"
  2. site:avito.ru "строительство бань"
  3. site:avito.ru "бытовки"
  4. site:avito.ru "строительные материалы"
  5. site:avito.ru "заборы ворота"
  6. site:avito.ru "наружная реклама"

При необходимости добавь названия интересующих городов в запрос. Используй Google Alerts с доставкой «RSS-фид». В GitHub Variables открой GOOGLE_ALERTS_RSS_URL и вставь URL всех RSS-лент, каждый с новой строки (не XML-содержимое). Старую ссылку не удаляй, добавь новые ниже. Затем запусти Run workflow и нажми «Загрузить новые кандидаты».

Узкие формулировки вроде «строительные материалы» могут давать мало находок. Попробуй отдельные запросы: site:avito.ru "газоблоки" Казань, site:avito.ru "баня под ключ" Уфа, site:avito.ru "откатные ворота" Новосибирск, site:avito.ru "вывески" Екатеринбург. Это примеры запросов, а не найденные объявления. Попробуй также новые оповещения Google Alerts с более конкретными запросами: site:avito.ru "модульный дом"; site:avito.ru "баня под ключ"; site:avito.ru "бытовка"; site:avito.ru "газоблок"; site:avito.ru "откатные ворота"; site:avito.ru "изготовление вывесок". Не удаляй существующие оповещения без необходимости. Поиск покрывает только индекс Google, не все объявления Авито. География определяется приблизительно по адресу ссылки. Недостатки объявления не генерируются без проверки. Данные клиентов хранятся в этом браузере, резервная копия — вкладка «Данные».

Новые потенциальные клиенты

Объявления из уведомлений Авито загружаются автоматически. Сначала показаны наиболее интересные по тематике. Открой объявление и используй готовое предложение бесплатного разбора. Сообщения никому не отправляются автоматически.

Получить файл в GitHub

Никаких ежедневных загрузок файлов. Объявления обновляются при открытии сайта. Если ссылка недоступна, она не заменяется выдуманным адресом.

Автоматическая синхронизация запустится при открытии приложения. Первую выгрузку можно запустить кнопкой в GitHub.

Автоматическое открытие объявлений

Один раз создай ключ в приложении, скопируй его в секрет GitHub AVITO_LINKS_KEY и сохрани тот же ключ в этом браузере. После этого ссылки из почты будут автоматически зашифровываться в GitHub и открываться у тебя по кнопке. Никому не отправляй ключ.

Секреты GitHub

Ключ хранится локально в браузере. На другом устройстве его потребуется ввести снова. Данные GitHub Pages публичны, но ссылки в них зашифрованы AES-256-GCM.

Автоматический анализ из Chrome

Один раз установи расширение «Авито Лиды — аудит карточек» из папки chrome-extension репозитория. Оставь эту страницу открытой и переходи по объявлениям: расширение само передаст доступный текст карточки и количество найденных изображений. Данные сохраняются в браузере, без передачи содержимого в GitHub.
